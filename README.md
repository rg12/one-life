# ONE LIFE — A Dossier

A life simulator built with React. Roll the dice for your family, choose your traits, and navigate careers, crime, politics, and the world stage.

**Play live:** [one-life.vercel.app](https://one-life.vercel.app)

## Features
- 7 career industries · 28 named employers · job hopping
- Sports, Arts, Business specializations
- 4-party political system · elections · PM career
- Underworld: crew hiring, empire expansion, gang notoriety
- Geopolitics: 6 world powers, crises, wars, treaties
- Asset catalog: cars, properties, yachts, private jets
- Relationships, kids, philanthropy, health
- Next-generation inheritance mode

## Tech
Vanilla React 18 (UMD) · pre-compiled JSX · zero build step · single HTML file
